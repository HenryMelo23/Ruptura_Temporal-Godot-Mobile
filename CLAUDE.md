# Regras do Agente (AI Instructions)

Ao trabalhar neste projeto de Godot, siga estritamente as seguintes diretrizes:

1. **Skills Obrigatórias:** SEMPRE consulte mentalmente e aplique as diretrizes das skills `game-development`, `godot-4` e `godot-gdscript` antes de sugerir ou alterar qualquer código.
2. **Contexto:** Este é um projeto focado em mobile (Android), portanto regras de otimização de performance, UI touch e loop do Godot são prioridade máxima.
3. **GDScript:** Utilize estritamente as tipagens fortes e recursos modernos do GDScript 2.0 (Godot 4).
