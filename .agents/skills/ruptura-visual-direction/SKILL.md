# Ruptura Visual Direction

Before implementing any screen, HUD, ability, animation, particle, shader, or visual state, define:

- Emotional objective.
- Primary focal element.
- Reading hierarchy.
- Local palette and why each color exists.
- Materials and texture language.
- Typography choice.
- Contrast level.
- Motion type and duration.
- Detail density.
- Narrative connection to Ruptura Temporal.
- Interaction states.
- Performance constraints.
- Target resolutions, including landscape mobile.
- Existing project references/assets.
- Elements to avoid.

Answer internally before editing:

- What should the player look at first?
- What should the player understand?
- What should the player feel?
- What changes on hover, focus, press, select, disabled, loading, and error?
- How does this belong to Ruptura Temporal?
- Does it still work at low resolution and mobile landscape?
- What is the rendering cost?

Do not finalize visuals that look generic, childish, corporate, misaligned, unreadable, over-glitched, over-glowing, or like placeholder art.
